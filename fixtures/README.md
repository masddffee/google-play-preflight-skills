# Synthetic fixtures

These are minimal static scanner inputs, not buildable production apps or evidence of Play approval. Dependency versions are test data; nothing is installed or executed. `expo-risk` has intentional risks. `expo-fixed` repairs selected configuration/declared workflow problems, but manual UNKNOWN results intentionally remain. Android, React Native and Flutter inputs exercise stack detection and literal target extraction. Generated reports use the fixed date 2026-09-28 for reproducibility.
