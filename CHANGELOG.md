# Changelog

## 1.0.0 — 2026-09-28

First executable release of play-preflight. Adds a dependency-free Node.js CLI, native GitHub Action, typed JSON context, 20 explicitly scoped check categories, dated target-API and Billing Library policy tables, merged-manifest parsing, terminal/JSON/Markdown/HTML/SARIF reports, safe file collection, reproducible fixtures, automated tests, offline package-install smoke testing, CI and a policy-source review workflow.

The skill is now an adapter to the CLI. Replaces stale SDK thresholds, unconditional alternative-billing prohibitions and the broken installation owner placeholder. UNKNOWN and attestation evidence are explicit. Keeps the original repository address and MIT license.

## 0.1.0 — legacy skill-only release

The original repository provided seven Markdown checklists, prompts, reference links and sample reports. It did not contain an executable scanner or GitHub Action. Its dated policy assertions and example results have been superseded by v1. Historical content remains in Git history.
