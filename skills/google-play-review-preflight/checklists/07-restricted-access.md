# Review access and runtime

These are human review prompts, not additional executable rules or guaranteed rejection criteria. Run the CLI first. Keep unsupported conclusions UNKNOWN and label manual findings separately from CLI output. Policy applicability depends on current official requirements and the actual app, market, audience and release.

Check that reviewers can reach all restricted functionality using current, working instructions through Play Console. Exercise the real release login, purchases, account deletion, permissions and startup behavior. The presence of authentication code does not prove review credentials are missing. Never place credentials in the preflight config or generated report. A developer's runtimeChecksReviewed declaration is an attestation, not a test run by this tool.

CLI categories: GP-ACCESS-001, GP-RUNTIME-001.

Source: https://support.google.com/googleplay/android-developer/answer/9859455?hl=en
